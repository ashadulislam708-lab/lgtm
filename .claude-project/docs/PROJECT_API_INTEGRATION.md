# API Integration Status: LGTM

## Overview

This is a **backend-only project**. No frontend, dashboard, or mobile applications are included.

The OrderFlow API is designed for testing the LGTM observability stack. API consumers are expected to use tools like Postman, curl, or custom scripts.

## API Testing Tools

| Tool | Purpose |
|------|---------|
| Swagger/OpenAPI | Auto-generated API documentation at `/api/docs` |
| Postman | Manual API testing and collection sharing |
| curl | CLI-based API testing |
| k6/Artillery | Load testing for observability scenarios |
